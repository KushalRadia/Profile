# Personal Portfolio Website

## 🌐 Overview
A dynamic and responsive personal portfolio website designed to showcase my skills, projects, and professional background. Built entirely with core web technologies, this site features custom animations, interactive elements, and a dedicated project showcase (including a custom Sliding Puzzle Game).

## ✨ Features
- **Responsive Design:** Optimized for a seamless viewing experience across desktops, tablets, and mobile devices.
- **Custom Animations:** Engaging visual elements powered by a dedicated `animation.css` stylesheet.
- **Project Showcase:** Highlights technical projects with visual thumbnails, including a featured Sliding Game.
- **Resume Integration:** Direct access to view and download my professional resume (`Kushal Radia.pdf`).
- **Clean UI/UX:** A minimalist and intuitive user interface built from the ground up without heavy frameworks.

## 🛠 Tech Stack
- **HTML5:** Semantic structure and content.
- **CSS3:** Layout styling and custom animations.
- **JavaScript (Vanilla):** DOM manipulation, interactive features, and logic.
